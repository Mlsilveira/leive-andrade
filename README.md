# Nova landing do Leive Andrade

Página estática (HTML + CSS já compilado). Abra `index.html` no navegador.

## Se mudar classes do Tailwind no HTML

O CSS está compilado em `tailwind.css` (não usa o script do CDN, que é lento). Depois de editar o HTML, gere de novo:

    npx tailwindcss@3.4.17 -c tailwind.config.js -i input.css -o tailwind.css --minify
